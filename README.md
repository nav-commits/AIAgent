# AI Agent Chat with LangChain, Groq & Next.js

A chat interface built with Next.js and React using LangChain’s Groq API, LangGraph agents, and community tools. It features message memory, a user-friendly chat UI, and handles async AI responses.

## Features

- Interactive chat UI resembling ChatGPT style
- Message history with user and AI messages
- Auto-scroll to newest message
- Async AI response handling with error and loading states
- Built with React, Next.js, Tailwind CSS, and LangChain libraries
